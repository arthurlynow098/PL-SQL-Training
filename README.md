# PL-SQL-Training

## Sobre o projeto

Exercícios introdutórios de PL/SQL. A pasta `Begin` contém exemplos de blocos e constantes.

## Como explorar

Use um ambiente Oracle compatível com PL/SQL. Abra os scripts da pasta `Begin` em seu cliente SQL e execute os blocos individualmente em uma base de estudos.
